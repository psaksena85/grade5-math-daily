Chapter 2 — Building the Multiplication Machine

Turn any 2-digit x 1-digit problem into an unbreakable step-by-step machine — arrays, area models, and the standard algorithm, all connected.

Module 1, Unit 2 Multi-digit multiplication Standard algorithm Regrouping

Yesterday you cracked the code of big numbers. Today you build a machine — a reliable set of steps that turns any 2-digit number times a 1-digit number into an answer you can trust, every single time. The machine has three settings: Concrete (build it), Pictorial (draw it), and Abstract (just do it fast). Once you understand why the machine works, you'll never need to guess again.

Stage 1 Concrete — Build the Array

Picture 23 x 4 as four rows of 23 objects. Split every row into 2 tens and 3 ones so the tens and ones stay separate — that split is the whole secret of the machine.

One row of 23 = 20 (blue tens) + 3 (orange ones). Four rows like this, stacked, is 23 x 4.

Stage 2 Pictorial — The Area Model

Instead of counting dots, draw 23 x 4 as a rectangle and slice it where the tens meet the ones. Now you have two easy rectangles instead of one hard one.

20 x 4 = 80the "tens" chunk
3 x 4 = 12the "ones" chunk

80 + 12 = 92, so 23 x 4 = 92. Every 2-digit x 1-digit problem splits this same way.

Stage 3 Abstract — The Standard Algorithm

Worked Example A — No regrouping

Step 1. 21 x 4  ->  multiply the ones: 1 x 4 = 4

Step 2. Multiply the tens: 2 x 4 = 8

Step 3. Put them together: 84

Estimate check: 20 x 4 = 80, and 84 is close to 80 -- reasonable.

Worked Example B — With regrouping

Step 1. 23 x 4  ->  multiply the ones: 3 x 4 = 12. Write the 2, carry the 1 ten.

Step 2. Multiply the tens: 2 x 4 = 8, then add the carried 1: 8 + 1 = 9

Step 3. Answer: 92 — matches the area model above!

Estimate check: 20 x 4 = 80, and 92 is close to 80 -- reasonable.

Try It The Multiplication Machine

Feed the machine a 2-digit number and a 1-digit number. It will split, multiply, and show every step.

Step 1. Split 23 into 20 + 3.
Step 2. Tens chunk: 20 x 4 = 80
Step 3. Ones chunk: 3 x 4 = 12
Step 4. Ones product is 10 or more, so carry 1 ten into the tens column.
Step 5. Add the chunks: 80 + 12 = 92

Recap What the Machine Taught You

Lock this in before homework

  • Every 2-digit x 1-digit problem splits into a tens part and a ones part -- that's true whether you're building, drawing, or using the standard algorithm.
  • Regrouping just means: if the ones product is 10 or more, write the ones digit and carry the tens digit over to add into the tens product.
  • Always estimate first (round to the nearest ten) so you can catch a mistake before you commit to an answer.
  • Word problems with equal groups -- rows of seats, boxes of apples, minutes per day -- are multiplication. Draw the bar model first.
